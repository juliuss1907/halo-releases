Dynamic Island cho Linux và Windows A Dynamic Island for Linux and Windows

Một khối mực trên đỉnh màn hình, viền bằng một vầng sáng đổi màu theo những gì đang diễn ra. Nhạc, lời bài hát, lịch, khay file, clipboard và thiết bị — nhẹ, không GPU, không webview. An ink island at the top of your screen, rimmed by a glow that changes colour with what is happening. Music, lyrics, calendar, file tray, clipboard and devices — light, no GPU, no webview.

Cài đặtInstall

Linux

  1. Tải Halo-x86_64.AppImage, đặt ở thư mục cố định (ví dụ ~/AppImages).Download Halo-x86_64.AppImage into a fixed folder (e.g. ~/AppImages).
  2. chmod +x Halo-x86_64.AppImage rồi chạy.and run it.
  3. Mở lại app để vào Cài đặt → Hệ thống → bật "Khởi động cùng máy".Run it again for Settings → System → "Start with the session".

Cần glibc 2.35+. Đầy đủ nhất trên KDE Plasma (Wayland); X11 dùng được.Needs glibc 2.35+. Fullest on KDE Plasma (Wayland); X11 works too.

Windows 10 / 11

  1. Tải halo-x86_64-windows.exe và chạy.Download halo-x86_64-windows.exe and run it.
  2. SmartScreen cảnh báo vì file chưa ký số: chọn "More info" → "Run anyway".SmartScreen warns because the file is not code-signed: "More info" → "Run anyway".
  3. Icon Halo nằm ở khay hệ thống: bấm để mở Cài đặt.Halo lives in the notification area: click it for Settings.

Mỗi file phát hành đều có chữ ký minisign (.minisig).Every release file is signed with minisign (.minisig).

Quyền riêng tưPrivacy

Halo không thu thập số liệu. Lịch sử clipboard chỉ nằm trong RAM; mục ghim lưu trên máy bạn. Lời bài hát chỉ gửi tên bài của các app nghe nhạc trong danh sách tới lrclib.net. Kiểm tra cập nhật chỉ đọc file từ GitHub. Halo collects no telemetry. Clipboard history stays in RAM; pins are stored on your machine. Lyrics only send the track name of allow-listed music apps to lrclib.net. Update checks only read files from GitHub.
