# Halo — downloads

**Halo** is a light Dynamic Island for Linux (Wayland / X11) and Windows.
Download page: **https://juliuss1907.github.io/halo-releases/**

**Halo** là "Dynamic Island" nhẹ cho Linux và Windows. Trang tải về: **https://juliuss1907.github.io/halo-releases/**

- Releases: the newest build is always at
  [`releases/latest`](https://github.com/juliuss1907/halo-releases/releases/latest).
- Every file is signed with [minisign](https://jedisct1.github.io/minisign/); the public key is
  [`halo.pub`](halo.pub). Halo checks these signatures itself when it updates.
- Bugs and ideas: [Issues](https://github.com/juliuss1907/halo-releases/issues).
